# Bossfighters Webapp

Webapp für eigene Boss-Fighters-QR-Bosse.

## Aktueller Boss
- `hellmo-crazby`

Nach Aktivierung von GitHub Pages lautet der Boss-Link:

`https://tacoonator.github.io/bossfighters-webapp/?boss=hellmo-crazby`

Diese URL kann dauerhaft für den Boss-QR-Code verwendet werden. Spätere Versionen ersetzen nur die Dateien im Repository.

## Struktur
```text
/
├─ index.html
├─ bosses/
│  └─ hellmo-crazby.js
└─ assets/
   └─ bosses/
      └─ hellmo-crazby.<bildformat>
```
